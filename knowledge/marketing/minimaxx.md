# MiniMaxx — XXL-Rehab Bariatric Wheelchair

**Content type: marketing/sales collateral (JDHG flyer), not a manufacturer IFU or ARTG/regulatory document.**

## What it is

XXL-Rehab MiniMaxx bariatric attendant-propelled wheelchair — lightweight tubular steel frame designed for safely transporting bariatric patients over long distances, foldable for storage. Optional "Push Assist" attendant-driven motor variant available.

## Standard features
- Adjustable backrest (removable for laundering)
- Removable 14cm dual-layer static foam cushion (viscoelastic memory foam top layer), 2-way stretch vapour-permeable waterproof PU fabric cover with HF-welded seams
- Height-adjustable push handles, ergonomically angled inward
- Removable PU-cushioned armrests
- Large rear wheels (solid rubber tyres) with option to reposition for centre-of-gravity adjustment; hand-operated wheel brake per rear wheel
- Swivel front castors; anti-tippers behind rear wheels
- Height-adjustable footrests supporting up to 100kg each, swing out of the way, sideways-adjustable footplates
- **Safe Working Load: 325kg**
- Optional factory-fitted disc brakes (must be requested at time of ordering)

## Push Assist variant
All standard features plus: detachable battery-powered dual-wheel drive system for uneven floors/external pathways; drive controls (on/off, forward/reverse, power output dial, throttle lever, LED indicators) on right-side push handle; external battery charger included; hook to secure lift/lower strap for drive motor; attendant-operated rear wheel disc brakes (standard on this model)
